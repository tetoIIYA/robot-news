Mambaで長時間のヒューマノイド動作を連続生成

人型ロボットがベッドから車椅子へ人体模型を自律移乗

全身ヒューマノイドの操作は、高次元の状態行動空間や接触の多さ、長い作業時間が障壁となる。この論文は、探索を導く最小限の構造として、全身操作のSparse Interaction Edges、長時間運搬のInteraction Gated Transport、衝突回避のHinted Object Pathの3手法を提案した。手法は剛体から人の運搬へ一般化でき、医療用マネキンのベッドから車椅子への移乗を、人の介入なしにヒューマノイドで実現した初の例だとする。体重や体格、外力の変化にも単一の方策で適応し、学習は単一GPUで1時間未満である。

人の全身動作5万時間でヒューマノイドVLAを学習

人型ロボットが家庭や職場の作業を行うため、Awaken-HIというVLAモデルとデータセットAwaken-Humanが発表された。データは約5万時間の一人称ステレオ映像と全身動作を対にし、100以上のスキルを含む。人の動作とロボット用に変換した動作を共有のアクション専門部で同時に予測する構造で、事前学習データを増やすと誤差が冪乗則で減ることを示した。T800実機への適応後、8つの個別タスクで平均成功率93.75%を達成し、GR00T N1.7とπ0.5を上回った。未知の物体や新しい物と置き場所の組み合わせにも一般化した。

ヒューマノイド全身制御の文脈内基盤モデルECHO

浙江大学、中国電信のTeleAI、上海科技大学、上海交通大学の研究チームが、ヒューマノイド向けの文脈内行動基盤モデルECHOを発表した。広範な動作を学んだ行動事前分布に、過去の状態と行動の履歴から動力学を読み取る残差制御器を組み合わせ、テスト時のパラメータ更新なしで環境に適応する。高動的モーションのベンチマークでは成功率が0.7633となり、同じ事前分布をMIASなしで学習した場合の0.4500を上回った。Unitree G1への展開では、激しいアクロバットや地形との接触を含む全身遠隔操作と、積載物への適応を示した。
