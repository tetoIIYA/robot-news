ヒューマノイド イベント・展示会 海外 11/09

Web Summit 2026開幕、ヒューマノイドが初の公式登壇

第10回Web Summitがリスボンで開幕し、木曜日まで開催される。主催者は物理AIを中心とする新段階と位置づけ、ヒューマノイドロボットが初めて公式スピーカーとして参加する。中国は過去最大の代表団を派遣し、Galbotの車輪移動・双腕ロボットが講演や各ブースでの実演に登場する。約7万人の参加、900人のスピーカー、2,000社超のスタートアップが見込まれる。プログラムはAIエージェントの活用や働き方の再構築などを扱う。

日程 2026-11-09 – 2026-11-12会場 リスボン国際見本市会場、MEOアリーナリスボン開催予定
