JAPAN BUILD TOKYO、建設向けフィジカルAI展示を新設

RX Japanは第11回「JAPAN BUILD TOKYO」を2026年12月2日から4日まで東京ビッグサイトで開催する。建設業の人手不足と時間外労働の上限規制を背景に、省力化・自動化技術を紹介する展示会だ。今回は「建設業×フィジカルAI」の特別展示を新設し、清水建設とpuerisomniaが四足歩行ロボットなどを出展する。四足ロボットがドローンを運び、1台のコントローラーで両機を操作する空陸連携システムも披露される。次世代建機パビリオンや建設DXアワード2026も開かれる。

日程 2026-12-02 – 2026-12-04会場 東京ビッグサイト東京開催予定
